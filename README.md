# LynxChain

LynxChain is a Hyperledger Fabric-based Platform utilizing real-time data processing and auto-scaling for scalable Network operations.

The key benefits of using LynxChain include:

- LynxChain is a Hyperledger Fabric-based
- Platform utilizing real-time data processing
- and auto-scaling for scalable Network

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/LynxChain.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

LynxChain is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
